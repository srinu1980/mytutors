
what is Embeddings in AI
Fast answer

Embeddings are a way of representing data (such as words, sentences, images, or documents) as lists of numbers (vectors) that capture their meaning. This lets AI models understand similarity and relationships mathematically.

A simple analogy

Imagine you're organizing books in a library.

If you organize them alphabetically, books about the same topic may end up far apart.
If you organize them by subject, books on similar topics are placed close together.

Embeddings work like the second approach: items with similar meanings have similar vectors.

For example:

Text	Simplified embedding (illustrative only)
"cat"	[0.82, -0.15, 0.44, ...]
"kitten"	[0.80, -0.17, 0.46, ...]
"dog"	[0.76, -0.21, 0.39, ...]
"car"	[-0.12, 0.91, -0.48, ...]

The vectors for cat and kitten are much closer than cat and car.

Why are embeddings useful?

Embeddings allow AI to compare meanings instead of exact words.

For example:

Query:

"How do I bake bread?"

A document saying:

"Guide to making homemade sourdough"

can still be found even though it doesn't contain the exact words "bake bread."

Common uses
Semantic search – Find documents by meaning instead of keywords.
Recommendation systems – Recommend similar products, movies, or songs.
Retrieval-Augmented Generation (RAG) – Retrieve relevant documents before asking an LLM to answer.
Clustering – Group similar documents or customers together.
Duplicate detection – Identify nearly identical content.
Classification – Categorize text, images, or other data.
How embeddings are created

An embedding model (often a neural network) learns patterns from large amounts of data.

For example:

Text
   ↓
Embedding Model
   ↓
[0.13, -0.55, 0.92, ... 1536 numbers]

The model converts text into a vector where semantic relationships are encoded.

Comparing embeddings

Once everything is converted into vectors, AI measures how close they are using metrics such as:

Cosine similarity (most common)
Euclidean distance
Dot product

Higher similarity means the items are more semantically related.

Example in a chatbot (RAG)

Suppose you have 10,000 company documents.

Convert every document into an embedding.
Store the embeddings in a vector database.

A user asks:

"How do I reset my password?"

Convert the question into an embedding.
Find the stored document embeddings that are most similar.
Provide those documents to the language model.
The model generates an answer based on the retrieved information.
Key points to remember
Embeddings are numerical representations of meaning, not just text.
Similar concepts produce vectors that are close together in vector space.
They power semantic search, recommendations, clustering, and RAG systems.
The vectors themselves are usually high-dimensional (e.g., 384, 768, or 1,536 dimensions), making them expressive enough to capture nuanced relationships.

In short, you can think of embeddings as a mathematical language that enables AI systems to understand and compare the meaning of information rather than just matching exact words

With overlap:

--------------------

        ↑

So:

chunk_size = 1000
chunk_overlap = 200

means chunks have approximately 200 characters of shared context at boundaries.

20. Complete basic implementation

A simple modern implementation can look like this:

from langchain_community.document_loaders import PyPDFLoader
from langchain_text_splitters import RecursiveCharacterTextSplitter
from langchain_openai import OpenAIEmbeddings, ChatOpenAI
from langchain_community.vectorstores import FAISS
from langchain_core.prompts import ChatPromptTemplate


# 1. Load PDF
loader = PyPDFLoader("documents/company_policy.pdf")
documents = loader.load()


# 2. Split document
text_splitter = RecursiveCharacterTextSplitter(
    chunk_size=1000,
    chunk_overlap=200
)

chunks = text_splitter.split_documents(documents)


# 3. Create embeddings
embeddings = OpenAIEmbeddings(
    model="text-embedding-3-small"
)


# 4. Create vector store
vectorstore = FAISS.from_documents(
    chunks,
    embeddings
)


# 5. Create retriever
retriever = vectorstore.as_retriever(
    search_kwargs={"k": 3}
)


# 6. Create LLM
llm = ChatOpenAI(
    model="gpt-4.1",
    temperature=0
)


# 7. Create prompt
prompt = ChatPromptTemplate.from_template("""
You are a helpful assistant.

Answer the question using ONLY the following context.

Context:
{context}

Question:
{question}

If the answer is not available in the context,
say "I don't know based on the provided documents."
""")


# 8. Ask question
question = "How many days of annual leave are available?"

retrieved_docs = retriever.invoke(question)


# 9. Combine retrieved documents
context = "\n\n".join(
    doc.page_content
    for doc in retrieved_docs
)


# 10. Create final prompt
messages = prompt.invoke({
    "context": context,
    "question": question
})


# 11. Ask LLM
response = llm.invoke(messages)


# 12. Print answer
print(response.content)
