2. Prompt Engineering
What is a Prompt?
A prompt is the instruction or input given to an AI model.

Simple Prompt
Explain Java.
However, this is very broad.

Better Prompt
Explain Java 21 for a beginner. Include important features, examples, and real-world use cases.
The second prompt provides more context and generally produces a better result.

What is Prompt Engineering?
Prompt Engineering is the process of designing effective instructions to obtain high-quality responses from AI models.

Step-by-Step Prompt Structure
A good prompt can contain:

1. Role
2. Task
3. Context
4. Instructions
5. Expected Output Format
Example
Role:
You are an experienced Java trainer.

Task:
Explain Spring Boot.

Context:
The audience consists of Java beginners.

Instructions:
Explain the concept step by step and provide examples.

Output:
Use headings, bullet points, and code examples.

4. Embeddings
What are Embeddings?
Computers cannot directly understand the meaning of text like humans do.

Therefore, AI converts text into numerical representations called embeddings.

Example
"Java Programming"
May be represented conceptually as:

[0.12, 0.89, 0.45, 0.23, ...]
The actual embedding can contain hundreds or thousands of numerical values.

Why Are Embeddings Useful?
Embeddings help computers understand:

Meaning

Context

Similarity

Relationships

Example
These sentences have similar meanings:

How do I learn Java?
What is the best way to study Java?
Although the words differ, their embeddings may be close to each other.

Embedding Flow
Text
  ↓
Embedding Model
  ↓
Numerical Vector
  ↓
Vector Database

16. Transformers
What is a Transformer?
The Transformer is a neural-network architecture that revolutionized Natural Language Processing.

Most modern LLMs are based on Transformer architectures.

Main Concept: Attention
Transformers use a mechanism called attention.

Consider:

The Java developer attended the Spring Boot training because he wanted to improve his skills.

When understanding the word he, the model uses context to determine that it refers to the Java developer.

This ability to understand relationships between words is supported by attention mechanisms.

For example:

User:
"What is the current balance of account 123?"
The LLM determines that it needs a tool:

getAccountBalance(123)
Application executes:

Database → ₹50,000
Then:

Tool Result
     ↓
    LLM
     ↓
"Your current balance is ₹50,000."
Important distinction
The LLM doesn't directly execute your Java method.

Instead:

LLM
 ↓
Tool Call Request
 ↓
Application
 ↓
Java Method/API/Database
 ↓
Tool Result
 ↓
LLM
This distinction is very important for enterprise AI development.

19. Context Engineering
Prompt engineering focuses primarily on instructions.

Context engineering focuses on providing the right information and context to the model at the right time.

For example:

User Query
   +
Conversation History
   +
Retrieved Documents
   +
User Information
   +
Tool Results
   +
System Instructions
        ↓
      LLM
Learn:

Context windows

Context selection

Context compression

Conversation history

Retrieval

Memory

Relevant context

Context prioritization

Long-context strategies

A useful distinction:

Prompt Engineering
        ↓
"What should I tell the model?"

Context Engineering
        ↓
"What information should I give the model?"
