

Optional class examples

In Java, the Java Optional class is used to avoid NullPointerException and handle nullable values in a clean way.

Basic Syntax

Optional<String> name = Optional.of("Srinivas");
1. Creating Optional Objects
a) Optional.of()
Used when value is NOT null.

Optional<String> name = Optional.of("Java");

System.out.println(name.get());
Output:

Java
b) Optional.ofNullable()
Used when value may be null.

String value = null;

Optional<String> data = Optional.ofNullable(value);

System.out.println(data.isPresent());
Output:

false
c) Optional.empty()
Creates empty Optional.

Optional<String> emptyObj = Optional.empty();

System.out.println(emptyObj.isPresent());
Output:

false

2. Checking Value
isPresent()
Optional<String> name = Optional.of("Spring Boot");

if(name.isPresent()) {
    System.out.println("Value exists");
}
3. Getting Value
get()
Optional<String> name = Optional.of("Microservices");

System.out.println(name.get());
Avoid get() without checking because it throws exception if empty.

4. Using orElse()
Returns default value if Optional is empty.

Optional<String> name = Optional.empty();

String result = name.orElse("Default Value");

System.out.println(result);
Output:

Default Value
5. Using orElseGet()
Optional<String> name = Optional.empty();

String result = name.orElseGet(() -> "Generated Value");

System.out.println(result);
6. Using orElseThrow()
Optional<String> name = Optional.empty();

String result = name.orElseThrow(() ->
        new RuntimeException("Value not found"));
7. Using ifPresent()
Executes code only if value exists.

Optional<String> name = Optional.of("Docker");

name.ifPresent(value -> System.out.println(value));
8. map() Example
Transforms value inside Optional.

Optional<String> name = Optional.of("java");

Optional<String> upper = name.map(String::toUpperCase);

System.out.println(upper.get());
Output:

JAVA
9. filter() Example
Optional<String> name = Optional.of("Spring");

Optional<String> result =
        name.filter(n -> n.startsWith("S"));

System.out.println(result.isPresent());
Output:

true
10. Real-Time Example
class User {
    private String email;

    public User(String email) {
        this.email = email;
    }

    public String getEmail() {
        return email;
    }
}

public class Test {
    public static void main(String[] args) {

        User user = new User(null);

        Optional<String> email =
                Optional.ofNullable(user.getEmail());

        String result =
                email.orElse("Email not available");

        System.out.println(result);
    }
}
Common Optional Methods
Method	Purpose
of()	Non-null value
ofNullable()	Nullable value
empty()	Empty Optional
isPresent()	Check value exists
get()	Get value
orElse()	Default value
orElseGet()	Supplier default
orElseThrow()	Throw exception
ifPresent()	Execute if value exists
map()	Transform value
filter()	Apply condition
Best Practices
✅ Use Optional for return types
✅ Avoid using Optional in fields/entities
✅ Prefer orElse() or orElseGet() over get()
✅ Use map() and filter() for clean functional style

Method Reference in Java 8
Method Reference is a short and clean way to call methods using :: operator.

It is mainly used with:

Lambda Expressions

Functional Interfaces

Streams API

Syntax
ClassName::methodName
Types of Method References
Type	Example
Static Method Reference	ClassName::staticMethod
Instance Method Reference	object::instanceMethod
Arbitrary Object Method Reference	ClassName::instanceMethod
Constructor Reference	ClassName::new
1. Static Method Reference
Without Method Reference
import java.util.function.Consumer;

public class Test {

    public static void print(String msg) {
        System.out.println(msg);
    }

    public static void main(String[] args) {

        Consumer<String> c =
                s -> Test.print(s);

        c.accept("Java 8");
    }
}
Using Method Reference
import java.util.function.Consumer;

public class Test {

    public static void print(String msg) {
        System.out.println(msg);
    }

    public static void main(String[] args) {

        Consumer<String> c = Test::print;

        c.accept("Java 8");
    }
}
Output:

Java 8
2. Instance Method Reference
public class Demo {

    public void show(String msg) {
        System.out.println(msg);
    }

    public static void main(String[] args) {

        Demo d = new Demo();

        java.util.function.Consumer<String> c =
                d::show;

        c.accept("Spring Boot");
    }
}

Spring Boot

Used for existing object methods.

Sealed Class in Java

Sealed classes were introduced in Java 17.

A sealed class restricts which classes can extend or implement it.

It provides:

Better control over inheritance
More secure design
Predictable class hierarchy
Syntax
sealed class Vehicle
    permits Car, Bike {
}

Only Car and Bike can extend Vehicle.

Example 1: Basic Sealed Class
sealed class Animal
        permits Dog, Cat {

    public void sound() {
        System.out.println("Animal sound");
    }
}

final class Dog extends Animal {

    public void bark() {
        System.out.println("Dog barking");
    }
}

final class Cat extends Animal {

    public void meow() {
        System.out.println("Cat meowing");
    }
}

public class Test {

    public static void main(String[] args) {

        Dog d = new Dog();

        d.sound();
        d.bark();
    }
}

Output:

Animal sound
Dog barking
Rules for Sealed Classes

A permitted subclass must be one of these:

Keyword	Meaning
final	Cannot be extended further
sealed	Can restrict subclasses again
non-sealed	Opens inheritance normally
Example 2: Using non-sealed
sealed class Shape
        permits Circle, Rectangle {
}

final class Circle extends Shape {
}

non-sealed class Rectangle extends Shape {
}

class Square extends Rectangle {
}

Here:

Circle cannot be extended
Rectangle allows further inheritance
Square can extend Rectangle
Example 3: Sealed Interface
sealed interface Payment
        permits CreditCard, UPI {
}

final class CreditCard
        implements Payment {
}

final class UPI
        implements Payment {
}
Real-Time Example
sealed class Employee
        permits Developer, Tester, Manager {
}







Record Class in Java 17

Record is a special type of class introduced in Java 16 (fully stable in Java 17).

It is used to create:

Immutable data objects
DTOs (Data Transfer Objects)
Simple model classes

Record automatically generates:

Constructor
Getters
toString()
equals()
hashCode()
Normal Class vs Record
Normal Class
class Employee {

    private final int id;
    private final String name;

    public Employee(int id, String name) {
        this.id = id;
        this.name = name;
    }

    public int getId() {
        return id;
    }

    public String getName() {
        return name;
    }
}
Record Class
record Employee(int id, String name) {
}

Same functionality with very less code.

Basic Example
record Student(int id, String name) {
}

public class Test {

    public static void main(String[] args) {

        Student s =
                new Student(101, "Srinivas");

        System.out.println(s.id());

        System.out.println(s.name());

        System.out.println(s);
    }
}

Output:

101
Srinivas
Student[id=101, name=Srinivas]
Automatically Generated Methods

For this record:

record User(int id, String name) {
}

Java automatically creates:

- Constructor
- id()
- name()
- equals()
- hashCode()
- toString()
Record with Custom Method
record Product(int id, String name, double price) {

    public void display() {
        System.out.println(name + " : " + price);
    }
}

public class Test {

    public static void main(String[] args) {

        Product p =
                new Product(1, "Laptop", 50000);

        p.display();
    }
}

Output:

Laptop : 50000.0
Compact Constructor

Used for validation.

record Employee(int id, String name) {

    public Employee {

        if(id <= 0) {
            throw new IllegalArgumentException(
                    "Invalid Id");
        }
    }
}
Immutable Nature

Record fields are automatically:

private
final

So values cannot be modified.

record Person(String name) {
}

Person p = new Person("Java");

// Not allowed
// p.name = "Spring";
