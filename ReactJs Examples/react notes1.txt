What is React JS?
====================

ReactJS is a popular front-end JavaScript library developers use to build user interfaces. 

It is mainly used to handle the view layer of web and mobile applications that follow a component-based architecture. 

Using ReactJS, developers can create reusable UI components that encapsulate the behavior and appearance of different parts of an application.

It is used to create Single Page Applications.





Core Features
==================

Virtual DOM: React updates only the changed parts of the DOM, resulting in faster rendering.

One-Way Data Binding: Ensures predictable and easy to debug data flow.

Component-Based Architecture: Breaks UI into reusable pieces, improving the code reusability and scalability.

What are Class Components?
============================

Class components are more complex than functional components. They are ES6 classes that extend from React.Component and can have their own state and lifecycle methods. 

Class components are also known as stateful components because they can manage their own state.


Class components are ES6 classes that return JSX.
Class components (ES6 class) extend the Component class in React.
Naming convention: Class Components always start with a capital letter.
Class Component takes Props (in the constructor) if needed.
Class component must have a render( ) method for returning JSX.




// Counter.js
import React, { Component } from 'react';

class Counter extends Component {
  constructor(props) {
    super(props);
    this.state = {
      count: 0
    };
  }

  increment = () => {
    this.setState({ count: this.state.count + 1 });
  };

  render() {
    return (
      <div>
        <h1>Count: {this.state.count}</h1>
        <button onClick={this.increment}>Increment</button>
      </div>
    );
  }
}

export default Counter;



Use the Component in App.js: Open src/App.js and modify the App component to use the Counter component:

// App.js
import React from 'react';
import Counter from './Counter';

function App() {
  return (
    <div>
      <Counter />
    </div>
  );
}

export default App;




Understanding State
===============
State is a built-in object in class components that allows components to create and manage their own data. State is managed within the component and can be updated using the setState method.



Example:
In the Counter component, we have a state object with a count property:

this.state = {
  count: 0
};
We update the state using the setState method:

increment = () => {
  this.setState({ count: this.state.count + 1 });
};





What is JSX?

JSX is a syntax extension for JavaScript that allows you to write HTML-like code within your JavaScript. It makes writing and understanding the structure of React components easier and more intuitive. JSX produces React “elements” which are then rendered to the DOM.



1. Elements: JSX elements are written using XML-like syntax.

	const element = <h1>Hello, world!</h1>;




2. Attributes: JSX attributes are similar to HTML attributes, but some attributes are written in camelCase (e.g., className instead of class).

const element = <div className="container">Content</div>;



3. Embedding Expressions: You can embed JavaScript expressions inside JSX by wrapping them in curly braces {}.

const name = 'Amit';

const element = <h1>Hello, {name}!</h1>;








Conditional Rendering with JSX
====================================

You can use JavaScript conditional operators to conditionally render elements.

Example:

// App.js

import React from 'react';

function App() {
  const isLoggedIn = true;
  return (
    <div>
      {isLoggedIn ? <h1>Welcome back!</h1> : <h1>Please sign up.</h1>}
    </div>
  );
}

export default App;






Lists and Keys in JSX

Rendering lists in React involves mapping over an array and returning a list of elements. 
Each element in the list should have a unique key prop.


// App.js
import React from 'react';

function App() {
  const names = ['Amit', 'Priya', 'Ravi'];
  return (
    <ul>
      {names.map((name, index) => (
        <li key={index}>{name}</li>
      ))}
    </ul>
  );
}

export default App;

What is State?

==================

State is a built-in object in React components. 

In the state object, we store property values that belong to the component. 
When the state object changes, the component re-renders to reflect the new data. 
The state object is modified with the setState() function in class components or the useState hook in functional components.



Creating State in Class Components
======================================


// StudentManagement.js

import React, { Component } from 'react';

class StudentManagement extends Component {
  constructor(props) {
    super(props);

    // Define the initial state
    this.state = {
      firstName: "Rahul",
      lastName: "Dravid",
      email: "rahul@outlook.com"
    };
  }


  // Render the UI
  render() {
    return (
      <div>
        <h1>Student Management System</h1>
        <p>First Name: {this.state.firstName}</p>
        <p>Last Name: {this.state.lastName}</p>
        <p>Email: {this.state.email}</p>
      </div>
    );
  }
}

export default StudentManagement;






Example:
Add State Update Methods: Modify the StudentManagement component to include methods for updating the state:
// StudentManagement.js
import React, { Component } from 'react';

class StudentManagement extends Component {
  constructor(props) {
    super(props);
    // Define the initial state
    this.state = {
      firstName: "Ramesh",
      lastName: "Fadatare",
      email: "ramesh@javaguides.com"
    };
  }

  // Method to update first name
  updateFirstName = () => {
    this.setState({ firstName: "Suresh" });
  };

  // Method to update last name
  updateLastName = () => {
    this.setState({ lastName: "Sharma" });
  };

  // Method to update email
  updateEmail = () => {
    this.setState({ email: "suresh@javaguides.com" });
  };

  // Render the UI
  render() {
    return (
      <div>
        <h1>Student Management System</h1>
        <p>First Name: {this.state.firstName}</p>
        <p>Last Name: {this.state.lastName}</p>
        <p>Email: {this.state.email}</p>
        <button onClick={this.updateFirstName}>Update First Name</button>
        <button onClick={this.updateLastName}>Update Last Name</button>
        <button onClick={this.updateEmail}>Update Email</button>
      </div>
    );
  }
}

export default StudentManagement;

State vs. Props


State: Managed within the component, can be changed, and is used for data that changes over time.


Props: Passed from parent to child components, read-only, and used for passing data and event handlers to child components.






What is Destructuring?

Destructuring is a JavaScript feature that allows you to extract values from arrays or properties from objects into distinct variables. It is a concise way to unpack values from arrays and objects.
