Spring Boot One-to-Many Mapping Example (Post ↔ Comments)
Business Requirement

A blog application contains:

One Post can have many Comments.
One Comment belongs to one Post.

Step 1: Comment Entity
package com.example.entity;

import jakarta.persistence.*;

@Entity
@Table(name = "comments")
public class Comment {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long commentId;

    private String commentText;

    @ManyToOne(fetch = FetchType.LAZY)
    @JoinColumn(name = "post_id")
    private Post post;

    // Getters and Setters
}
Step 2: Post Entity
package com.example.entity;

import jakarta.persistence.*;

import java.util.ArrayList;
import java.util.List;

@Entity
@Table(name = "posts")
public class Post {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long postId;

    private String title;

    private String content;

    @OneToMany(
            mappedBy = "post",
            cascade = CascadeType.ALL,
            orphanRemoval = true)
    private List<Comment> comments =
            new ArrayList<>();

    // Getters and Setters
}
Why mappedBy = "post"?
@OneToMany(mappedBy = "post")
private List<Comment> comments;

Here:

@ManyToOne
@JoinColumn(name = "post_id")
private Post post;

The field name is:

post

Therefore:

mappedBy = "post"

This tells Hibernate:

"The Comment entity owns the relationship and contains the foreign key."

Without mappedBy, Hibernate creates an unnecessary join table.

Step 5: Service Layer
PostService
package com.example.service;

import com.example.dto.PostRequestDTO;
import com.example.dto.PostResponseDTO;

import java.util.List;

public interface PostService {

    PostResponseDTO createPost(PostRequestDTO dto);

    PostResponseDTO getPostById(Long id);

    List<PostResponseDTO> getAllPosts();

    void deletePost(Long id);
}
PostServiceImpl
package com.example.service;

import com.example.dto.CommentDTO;
import com.example.dto.PostRequestDTO;
import com.example.dto.PostResponseDTO;
import com.example.entity.Comment;
import com.example.entity.Post;
import com.example.repository.PostRepository;
import lombok.RequiredArgsConstructor;
import org.springframework.stereotype.Service;

import java.util.List;

@Service
@RequiredArgsConstructor
public class PostServiceImpl
        implements PostService {

    private final PostRepository postRepository;

    @Override
    public PostResponseDTO createPost(
            PostRequestDTO dto) {

        Post post = new Post();
        post.setTitle(dto.title());
        post.setContent(dto.content());

        List<Comment> comments =
                dto.comments()
                        .stream()
                        .map(commentDTO -> {

                            Comment comment =
                                    new Comment();

                            comment.setCommentText(
                                    commentDTO.commentText());

                            comment.setPost(post);

                            return comment;

                        })
                        .toList();

        post.setComments(comments);

        Post savedPost =
                postRepository.save(post);

        return mapToDTO(savedPost);
    }

    @Override
    public PostResponseDTO getPostById(Long id) {

        Post post =
                postRepository.findById(id)
                        .orElseThrow(() ->
                                new RuntimeException(
                                        "Post not found"));

        return mapToDTO(post);
    }

    @Override
    public List<PostResponseDTO> getAllPosts() {

        return postRepository.findAll()
                .stream()
                .map(this::mapToDTO)
                .toList();
    }

    @Override
    public void deletePost(Long id) {

        postRepository.deleteById(id);
    }

    private PostResponseDTO mapToDTO(
            Post post) {

        return new PostResponseDTO(

                post.getPostId(),

                post.getTitle(),

                post.getContent(),

                post.getComments()
                        .stream()
                        .map(Comment::getCommentText)
                        .toList()
        );
    }
}
Step 6: REST Controller
package com.example.controller;

import com.example.dto.PostRequestDTO;
import com.example.dto.PostResponseDTO;
import com.example.service.PostService;
import jakarta.validation.Valid;
import lombok.RequiredArgsConstructor;
import org.springframework.http.HttpStatus;
import org.springframework.http.ResponseEntity;
import org.springframework.web.bind.annotation.*;

import java.util.List;

@RestController
@RequestMapping("/api/posts")
@RequiredArgsConstructor
public class PostController {

    private final PostService postService;

    @PostMapping
    public ResponseEntity<PostResponseDTO>
    createPost(
            @Valid
            @RequestBody PostRequestDTO dto) {

        return ResponseEntity.status(
                HttpStatus.CREATED)
                .body(
                        postService.createPost(dto)
                );
    }

    @GetMapping("/{id}")
    public ResponseEntity<PostResponseDTO>
    getPostById(
            @PathVariable Long id) {

        return ResponseEntity.ok(
                postService.getPostById(id)
        );
    }

    @GetMapping
    public ResponseEntity<List<PostResponseDTO>>
    getAllPosts() {

        return ResponseEntity.ok(
                postService.getAllPosts()
        );
    }

    @DeleteMapping("/{id}")
    public ResponseEntity<String>
    deletePost(
            @PathVariable Long id) {

        postService.deletePost(id);

        return ResponseEntity.ok(
                "Post deleted successfully");
    }
}

How CascadeType.ALL Works
@OneToMany(
    mappedBy = "post",
    cascade = CascadeType.ALL
)
private List<Comment> comments;

When:

postRepository.save(post);

Hibernate automatically:

1. Save Post
2. Generate post_id
3. Save Comment-1 with post_id
4. Save Comment-2 with post_id
5. Save Comment-3 with post_id

No need to call:

commentRepository.save(comment);

Key Interview Questions
Why is @ManyToOne placed in Comment?

Because the foreign key (post_id) exists in the comments table.

@ManyToOne
@JoinColumn(name = "post_id")
private Post post;
What does mappedBy = "post" mean?

It tells Hibernate that the relationship is managed by the post field in the Comment entity.

What is orphanRemoval = true?
@OneToMany(
    mappedBy = "post",
    orphanRemoval = true
)

If a comment is removed from the post's comments list, Hibernate automatically deletes that comment from the database.

This Post–Comment example is one of the most common real-world implementations of @OneToMany and @ManyToOne relationships in Spring Boot applications such as blogs, news portals, discussion forums, and social media platforms.
