JUnit 5 is the latest version of the JUnit testing framework used to write and execute automated tests for Java applications.

Understanding @Test
-----------------------

The @Test annotation tells JUnit:

"Execute this method as a test case."

Example:

@Test
void testMultiplication() {

    assertEquals(20, 4 * 5);
}


Assertions
--------------

Assertions compare actual results with expected results.

assertEquals()

Checks whether two values are equal.

@Test
void testAddition() {

    assertEquals(50, 20 + 30);
}



Test Lifecycle Annotations
-----------------------------

JUnit provides lifecycle methods that execute before and after tests.

@BeforeEach

Runs before every test.

@BeforeEach
void init() {

    System.out.println("Before Test");
}

Example Output:

Before Test

Before Test
Test 2
@AfterEach

Runs after every test.

@AfterEach
void cleanup() {

    System.out.println("After Test");
}
@BeforeAll

Runs only once before all tests.

@BeforeAll
static void start() {

    System.out.println("Application Started");
}
@AfterAll

Runs only once after all tests.

@AfterAll
static void stop() {

    System.out.println("Application Closed");
}

What is Mockito?

Mockito is a popular Java mocking framework used along with JUnit to create mock objects for unit testing.

It helps us test a class in isolation without depending on external systems like:

Database
REST APIs
File Systems
Email Services
Third-party Services


Why Mockito?

Consider a Spring Boot application:

EmployeeController
        |
        ↓
EmployeeService
        |
        ↓
EmployeeRepository
        |
        ↓
      Database

Suppose we want to test EmployeeService.

Without Mockito:

Test requires a database connection.
Test execution becomes slow.
Failures may occur due to DB issues.

With Mockito:

EmployeeService
       |
       ↓
Mock EmployeeRepository

No database is required.

Tests become:

✅ Fast

✅ Independent

✅ Reliable

Real-Time Example

EmployeeService
@Service
@RequiredArgsConstructor
public class EmployeeService {

    private final EmployeeRepository repository;

    public Employee findById(Long id) {

        return repository.findById(id)
                .orElseThrow(() ->
                        new RuntimeException(
                                "Employee Not Found"));
    }
}


Problem

While testing:

repository.findById(id)

tries to connect to the database.

Instead of using a real database, Mockito creates a fake repository.

Mockito Dependency

Spring Boot already provides Mockito through:

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
</dependency>


Core Mockito Annotations
-----------------------------
Annotation	Purpose

@Mock		Creates fake object
@InjectMocks	Injects mock objects
@Spy		Partial mocking
@Captor		Captures arguments
@ExtendWith(MockitoExtension.class)	Enables Mockito in JUnit 5
@Mock Annotation	Creates a fake object.



Example:

@Mock
EmployeeRepository repository;

Mockito creates:

EmployeeRepository repository =
        Mockito.mock(EmployeeRepository.class);
@InjectMocks Annotation

Injects mocked dependencies into the class being tested.

Example:

@InjectMocks
EmployeeService service;

Mockito internally does:

EmployeeService service =
        new EmployeeService(repository);

where repository is the mocked object.

Understanding when()

Mockito uses:

when(...)

to define mock behavior.

Example:

when(repository.findById(1L))
        .thenReturn(Optional.of(employee));

Meaning:

When repository.findById(1L)
is called

Return employee
thenReturn()

Returns predefined data.

when(repository.findAll())
        .thenReturn(employeeList);


Example: Testing findAll()

Service
public List<Employee> findAll() {

    return repository.findAll();
}


Test
@Test
void shouldReturnAllEmployees() {

    List<Employee> employees =
            Arrays.asList(
                    new Employee(1L,"John","IT"),
                    new Employee(2L,"David","HR"));

    when(repository.findAll())
            .thenReturn(employees);

    List<Employee> result =
            service.findAll();

    assertEquals(2, result.size());
}


verify()

Used to check whether a method was called.

Example:

verify(repository).findById(1L);

Meaning:

Ensure repository.findById(1L)
was executed exactly once.


verify Example

@Test
void shouldCallRepositoryMethod() {

    Employee employee =
            new Employee(
                    1L,
                    "John",
                    "IT");

    when(repository.findById(1L))
            .thenReturn(Optional.of(employee));

    service.findById(1L);

    verify(repository).findById(1L);
}


verify Times

Called once:

verify(repository,times(1))
        .findById(1L);

Called twice:

verify(repository,times(2))
        .findById(1L);

Never called:

verify(repository,never())
        .save(any());

Instead of exact values:

eq()

package com.example.employee.service;

import java.util.List;

import org.springframework.stereotype.Service;

import com.example.employee.exception.EmployeeNotFoundException;
import com.example.employee.model.Employee;
import com.example.employee.repository.EmployeeRepository;

@Service
public class EmployeeService {

    private EmployeeRepository repository;

    public EmployeeService(EmployeeRepository repository) {
        this.repository = repository;
    }

    // Create
    public Employee saveEmployee(Employee employee) {
        return repository.save(employee);
    }

    // Read All
    public List<Employee> getAllEmployees() {
        return repository.findAll();
    }

    // Read By Id
    public Employee getEmployeeById(Long id) {

        return repository.findById(id)
                .orElseThrow(() ->
                        new EmployeeNotFoundException("Employee Not Found"));
    }

    // Update
    public Employee updateEmployee(Long id, Employee employee) {

        Employee existingEmployee =
                repository.findById(id)
                        .orElseThrow(() ->
                                new EmployeeNotFoundException("Employee Not Found"));

        existingEmployee.setName(employee.getName());
        existingEmployee.setEmail(employee.getEmail());
        existingEmployee.setSalary(employee.getSalary());

        return repository.save(existingEmployee);
    }

    // Delete
    public void deleteEmployee(Long id) {

        repository.findById(id)
                .orElseThrow(() ->
                        new EmployeeNotFoundException("Employee Not Found"));

        repository.deleteById(id);
    }
}

EmployeeServiceTest

package com.example.employee.service;

import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.Mockito.*;

import java.util.Arrays;
import java.util.List;
import java.util.Optional;

import com.example.employee.exception.EmployeeNotFoundException;
import com.example.employee.model.Employee;
import com.example.employee.repository.EmployeeRepository;

import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;

import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;

@ExtendWith(MockitoExtension.class)
class EmployeeServiceTest {

    @Mock
    private EmployeeRepository repository;

    @InjectMocks
    private EmployeeService service;

    private Employee employee;

    @BeforeEach
    void setup() {

        employee = Employee.builder()
                .id(1L)
                .name("John")
                .email("john@gmail.com")
                .salary(50000.0)
                .build();
    }

    // ==========================
    // CREATE TEST CASE
    // ==========================

    @Test
    void saveEmployeeTest() {

        when(repository.save(any(Employee.class)))
                .thenReturn(employee);

        Employee savedEmployee =
                service.saveEmployee(employee);

        assertNotNull(savedEmployee);
        assertEquals("John", savedEmployee.getName());

        verify(repository, times(1))
                .save(employee);
    }

    // ==========================
    // GET ALL TEST CASE
    // ==========================

    @Test
    void getAllEmployeesTest() {

        List<Employee> employeeList =
                Arrays.asList(
                        employee,
                        new Employee(2L,
                                "David",
                                "david@gmail.com",
                                60000.0)
                );

        when(repository.findAll())
                .thenReturn(employeeList);

        List<Employee> result =
                service.getAllEmployees();

        assertEquals(2, result.size());

        verify(repository, times(1))
                .findAll();
    }

    // ==========================
    // GET BY ID TEST CASE
    // ==========================

    @Test
    void getEmployeeByIdTest() {

        when(repository.findById(1L))
                .thenReturn(Optional.of(employee));

        Employee result =
                service.getEmployeeById(1L);

        assertEquals("John",
                result.getName());

        verify(repository)
                .findById(1L);
    }

    // ==========================
    // GET BY ID EXCEPTION TEST
    // ==========================

    @Test
    void getEmployeeByIdNotFoundTest() {

        when(repository.findById(1L))
                .thenReturn(Optional.empty());

        assertThrows(
                EmployeeNotFoundException.class,
                () -> service.getEmployeeById(1L)
        );
    }

    // ==========================
    // UPDATE TEST CASE
    // ==========================

    @Test
    void updateEmployeeTest() {

        Employee updatedEmployee =
                Employee.builder()
                        .id(1L)
                        .name("Updated John")
                        .email("updated@gmail.com")
                        .salary(70000.0)
                        .build();

        when(repository.findById(1L))
                .thenReturn(Optional.of(employee));

        when(repository.save(any(Employee.class)))
                .thenReturn(updatedEmployee);

        Employee result =
                service.updateEmployee(1L,
                        updatedEmployee);

        assertEquals(
                "Updated John",
                result.getName()
        );

        assertEquals(
                70000.0,
                result.getSalary()
        );

        verify(repository)
                .findById(1L);

        verify(repository)
                .save(any(Employee.class));
    }

    // ==========================
    // DELETE TEST CASE
    // ==========================

    @Test
    void deleteEmployeeTest() {

        when(repository.findById(1L))
                .thenReturn(Optional.of(employee));

        doNothing()
                .when(repository)
                .deleteById(1L);

        service.deleteEmployee(1L);

        verify(repository)
                .deleteById(1L);
    }

    // ==========================
    // DELETE EXCEPTION TEST
    // ==========================

    @Test
    void deleteEmployeeNotFoundTest() {

        when(repository.findById(1L))
                .thenReturn(Optional.empty());

        assertThrows(
                EmployeeNotFoundException.class,
                () -> service.deleteEmployee(1L)
        );
    }
}

What is Mockito?

Mockito is a Java mocking framework used to create fake (mock) objects for testing.

It allows us to test a class independently without using actual database, API, or external services.


Why Mockito?

Suppose:

@Service
public class EmployeeService {

    private EmployeeRepository repository;

    public EmployeeService(EmployeeRepository repository) {
        this.repository = repository;
    }
}


While testing EmployeeService, we don't want to connect to a real database.

Mockito creates a fake repository and returns predefined data.

Common Mockito Annotations

Annotation		Purpose
================================================
@Mock			Creates mock object
@InjectMocks		Injects mock objects into class under test
@ExtendWith(MockitoExtension.class) Enables Mockito support in JUnit 5


Example

@ExtendWith(MockitoExtension.class)
class EmployeeServiceTest {

    @Mock
    private EmployeeRepository repository;

    @InjectMocks
    private EmployeeService service;
}


Used Mockito Methods
---------------------
1. when()

Used to define mock behavior.

when(repository.findById(1L))
        .thenReturn(Optional.of(employee));


2. verify()

Verifies method invocation.

verify(repository, times(1))
        .save(employee);

3. any()

Matches any object.

when(repository.save(any(Employee.class)))
        .thenReturn(employee);


4. doNothing()

Used for void methods.

doNothing()
    .when(repository)
    .deleteById(1L);


5. doThrow()

Used to throw exceptions.


doThrow(new RuntimeException())
    .when(repository)
    .deleteById(1L);

Provides assertions	Provides mock behavior
