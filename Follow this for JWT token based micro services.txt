Based on all our previous discussions, I recommend building the project in the following order. This architecture is close to what many enterprise Spring Boot applications use.

                     Client
                        │
                        ▼
                 API Gateway (JWT Validation)
                        │
          ┌─────────────┴─────────────┐
          ▼                           ▼
    Auth Service                Employee Service
(Login/Register/JWT)           (Business APIs)
          │
          └─────────────┐
                        ▼
                  Eureka Server
