Explain basics of reactjs redux?

Since you've already learned React Hooks (useState, useEffect, useContext, useReducer, useMemo, useCallback), the next important topic is Redux.

What is Redux?
Redux is a state management library used to manage and share application data across multiple React components.

Instead of passing data from one component to another using props (called prop drilling), Redux stores the data in one central store, and any component can access it.

Why do we need Redux?
Without Redux

 ├── Dashboard

This is called Prop Drilling.

Every component directly accesses the store.

No prop drilling.

Redux Toolkit (Modern Redux)
Nowadays, developers use Redux Toolkit (RTK) instead of writing Redux manually because it reduces boilerplate code and follows best practices.

Benefits:

Less code

Easier configuration

Built-in support for immutable updates

Better performance

Recommended by the Redux team

When Should You Use Redux?
Use Redux when:

Multiple components need the same data.

Your application has complex state.

You need predictable state updates.

You're building medium to large applications.

Avoid Redux for very small applications where React's built-in state (useState) or useContext is sufficient.

Step 2: Create Redux Store
app/store.js
import { configureStore } from "@reduxjs/toolkit";
import counterReducer from "../features/counter/counterSlice";

export const store = configureStore({
    reducer: {
        counter: counterReducer
    }
});
Explanation

configureStore() creates the Redux store.

counter is the name of the state.

counterReducer controls how the state changes.

Step 3: Create Counter Slice
features/counter/counterSlice.js
import { createSlice } from "@reduxjs/toolkit";

const initialState = {
    value: 0
};

const counterSlice = createSlice({
    name: "counter",
    initialState,

    reducers: {

        increment: (state) => {
            state.value++;
        },

        decrement: (state) => {
            state.value--;
        }

    }

});

export const { increment, decrement } = counterSlice.actions;

export default counterSlice.reducer;
What is happening?

   value:0
}

}
When

dispatch(decrement())

Step 5: Use Redux in App
App.jsx
import { useSelector, useDispatch } from "react-redux";
import { increment, decrement } from "./features/counter/counterSlice";

function App() {

    const count = useSelector((state) => state.counter.value);

    const dispatch = useDispatch();

    return (

        <div style={{ textAlign: "center", marginTop: "50px" }}>

            <h1>Redux Counter Example</h1>

            <h2>{count}</h2>

            <button onClick={() => dispatch(increment())}>
                Increment
            </button>

            <button
                onClick={() => dispatch(decrement())}
                style={{ marginLeft: "10px" }}
            >
                Decrement
            </button>

        </div>

    );

}

export default App;
