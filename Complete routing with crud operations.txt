ReactJS Routing and Spring Boot Integration
What is Routing in ReactJS?
Routing is the process of navigating between different pages (components) in a React Single Page Application (SPA) without reloading the browser.

Instead of loading a new HTML page every time, React dynamically changes the displayed component.

Example
Without Routing:

http://localhost:5173
Everything is displayed on one page.

With Routing:

http://localhost:5173/
http://localhost:5173/login
http://localhost:5173/employees
http://localhost:5173/add-employee
http://localhost:5173/edit/101
Each URL displays a different React component.

Why do we need Routing?
Suppose you are developing an Employee Management System.

You need multiple pages:

Home

Login

Dashboard

Employee List

Add Employee

Edit Employee

About

Contact

Routing helps users navigate between these pages.

Step 2: Configure Routes
App.jsx
import { Routes, Route } from "react-router-dom";

import Home from "./components/Home";
import Login from "./components/Login";
import EmployeeList from "./components/EmployeeList";
import AddEmployee from "./components/AddEmployee";
import EditEmployee from "./components/EditEmployee";

function App() {

    return (

        <Routes>

            <Route path="/" element={<Home />} />

            <Route path="/login" element={<Login />} />

            <Route path="/employees" element={<EmployeeList />} />

            <Route path="/add" element={<AddEmployee />} />

            <Route path="/edit/:id" element={<EditEmployee />} />

        </Routes>

    );

}

export default App;

import axios from "axios";

const API_URL = "http://localhost:8080/employees";

export const getEmployees = () => {
    return axios.get(API_URL);
};


Display Data in React


import { useEffect, useState } from "react";
import { getEmployees } from "../services/EmployeeService";

function EmployeeList() {

    const [employees, setEmployees] = useState([]);

    useEffect(() => {

        getEmployees()
            .then((response) => {
                setEmployees(response.data);
            })
            .catch((error) => {
                console.error(error);
            });

    }, []);

    return (

        <table>

            <tbody>

                {
                    employees.map(emp => (

                        <tr key={emp.id}>
                            <td>{emp.id}</td>
                            <td>{emp.name}</td>
                            <td>{emp.salary}</td>
                        </tr>

                    ))
                }

            </tbody>

        </table>

    );

}

export default EmployeeList;
