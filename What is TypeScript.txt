What is TypeScript?

TypeScript is an open-source programming language developed by Microsoft.

It is a superset of JavaScript, which means:

Every JavaScript program is valid TypeScript.
TypeScript adds additional features such as:
Static Typing
Interfaces
Enums
Generics
Access Modifiers
Decorators
Better Tooling

TypeScript code is compiled into JavaScript before it runs in the browser or Node.js.

Why TypeScript?

JavaScript is dynamically typed.

Example:

let age = 25;

age = "Twenty Five";

console.log(age);

No error occurs until runtime.

TypeScript catches this during compilation.

let age: number = 25;

age = "Twenty Five";

Compilation Error:

Type 'string' is not assignable to type 'number'.

Interview Questions
1. What is TypeScript?

TypeScript is an open-source, statically typed superset of JavaScript developed by Microsoft that compiles to JavaScript.

2. Why use TypeScript?
Static typing
Better maintainability
Compile-time error checking
Improved IDE support
Suitable for large-scale applications
3. Is every JavaScript program valid TypeScript?

Yes. JavaScript is a subset of TypeScript, so existing JavaScript code can generally be used in TypeScript projects.

4. What is the TypeScript compiler?

The TypeScript compiler (tsc) converts TypeScript (.ts) files into JavaScript (.js) files.

5. What is tsconfig.json?

tsconfig.json is the configuration file that controls how the TypeScript compiler compiles the project.

What is a Data Type?

A data type specifies the kind of value that a variable can store.

Example:

Number
String
Boolean
Array
Object
Variable Declaration

TypeScript supports three keywords:

let
const
var
Using let
let name: string = "John";
let age: number = 25;

console.log(name);
console.log(age);

Output:

John
25
Using const
const PI: number = 3.14159;

console.log(PI);

Output:

3.14159

const variables cannot be reassigned.

const PI = 3.14;

PI = 5;

Compilation Error:

Cannot assign to 'PI' because it is a constant.
Using var
var city: string = "Hyderabad";

console.log(city);

Recommendation: Avoid var in modern TypeScript. Prefer let and const.

Any

The any type disables type checking.

let value: any = 100;

value = "Hello";

console.log(value);

Best Practice: Avoid any unless absolutely necessary.

Unknown

unknown is safer than any.

    console.log(data.toUpperCase());
}
Void

Used for functions that do not return a value.

    console.log("Welcome");
}

Never

Represents functions that never successfully complete.

    throw new Error(message);
}

What is a Function?

A function is a reusable block of code that performs a specific task.

Syntax

1. What is the difference between a normal function and an arrow function?
Normal functions have their own this context.
Arrow functions inherit this from the surrounding scope.
2. What are optional parameters?

Optional parameters allow arguments to be omitted when calling a function. They are declared using ?.

3. What are rest parameters?

Rest parameters collect multiple arguments into a single array.

4. What is the spread operator?

The spread operator (...) expands elements from an array or properties from an object into another array or object.

5. What are template literals?

Template literals use backticks (`) and ${} placeholders to embed expressions within strings.

What is Object-Oriented Programming (OOP)?

Object-Oriented Programming (OOP) is a programming paradigm that organizes code into objects, which contain properties (data) and methods (behavior).

Four Pillars of OOP
Encapsulation
Inheritance
Polymorphism
Abstraction
Class

A class is a blueprint for creating objects.

Syntax
class ClassName {

}
Creating a Class
class Employee {

    id: number = 101;

    name: string = "John";

    display(): void {
        console.log(this.id);
        console.log(this.name);
    }

}

const emp = new Employee();

emp.display();
Output
101
John
Constructor

A constructor initializes an object.

class Employee {

    id: number;
    name: string;

    constructor(id: number, name: string) {

        this.id = id;
        this.name = name;

    }

    display(): void {

        console.log(this.id);
        console.log(this.name);

    }

}

const emp = new Employee(101, "Ramesh");

emp.display();
Output
101
Ramesh
Parameter Properties (Short Syntax)

Instead of writing multiple assignments:

class Employee {

    constructor(
        public id: number,
        public name: string,
        public salary: number
    ) {
    }

}

const emp = new Employee(101, "John", 50000);

console.log(emp);
Access Modifiers
Public (Default)

Accessible everywhere.

class Employee {

    public name = "John";

}

const emp = new Employee();

console.log(emp.name);
Private

Accessible only inside the class.

class Employee {

    private salary = 50000;

}

The following causes a compilation error:

const emp = new Employee();

console.log(emp.salary);
Protected

Accessible inside the class and its subclasses.

class Person {

    protected age = 30;

}

class Employee extends Person {

    display() {
        console.log(this.age);
    }

}
Readonly

Can only be assigned during declaration or in the constructor.

class Employee {

    readonly company = "ABC Ltd";

}

const emp = new Employee();

console.log(emp.company);

Attempting to change it results in a compilation error.

Getters and Setters
class Employee {

    private salary = 50000;

    get employeeSalary(): number {
        return this.salary;
    }

    set employeeSalary(value: number) {
        this.salary = value;
    }

}

const emp = new Employee();

emp.employeeSalary = 70000;

console.log(emp.employeeSalary);
Inheritance

Inheritance allows one class to acquire the properties and methods of another.

class Person {

    display() {
        console.log("Person Class");
    }

}

class Employee extends Person {

}

const emp = new Employee();

emp.display();
Output
Person Class
Method Overriding
class Person {

    display() {
        console.log("Person");
    }

}

class Employee extends Person {

    override display() {
        console.log("Employee");
    }

}

const emp = new Employee();

emp.display();
Output
Employee
super Keyword
class Person {

    constructor(public name: string) {
    }

}

class Employee extends Person {

    constructor(name: string) {
        super(name);
    }

}

const emp = new Employee("John");

console.log(emp.name);
Abstract Class

An abstract class cannot be instantiated directly.

abstract class Shape {

    abstract area(): number;

}

class Circle extends Shape {

    area(): number {
        return 3.14 * 10 * 10;
    }

}

const circle = new Circle();

console.log(circle.area());
Interface

Interfaces define a contract that classes must implement.

interface Employee {

    id: number;

    name: string;

    display(): void;

}

class Manager implements Employee {

    id = 101;

    name = "John";

    display(): void {
        console.log(this.id);
        console.log(this.name);
    }

}

const manager = new Manager();

manager.display();
Multiple Interfaces
interface Printable {

    print(): void;

}

interface Scannable {

    scan(): void;

}

class Printer implements Printable, Scannable {

    print() {
        console.log("Printing...");
    }

    scan() {
        console.log("Scanning...");
    }

}
Static Members

Static members belong to the class, not individual objects.

class Employee {

    static company = "ABC Technologies";

}

console.log(Employee.company);
Real-Time Example
class BankAccount {

    constructor(

        public accountNumber: number,

        public customerName: string,

        private balance: number

    ) {
    }

    deposit(amount: number): void {

        this.balance += amount;

    }

    withdraw(amount: number): void {

        this.balance -= amount;

    }

    getBalance(): number {

        return this.balance;

    }

}

const account = new BankAccount(
    1001,
    "Ramesh",
    5000
);

account.deposit(2000);

account.withdraw(1000);

console.log(account.getBalance());
Output
6000
Best Practices
Use private for sensitive fields.
Use readonly for values that should not change.
Prefer interfaces for defining contracts.
Use inheritance only when there is a true "is-a" relationship.
Keep classes focused on a single responsibility.
Interview Questions
1. What is OOP?

Object-Oriented Programming is a programming paradigm based on classes and objects that promotes code reusability and maintainability.

2. What is the difference between a class and an object?
Class: Blueprint or template.
Object: Instance of a class.
3. What is the difference between private and protected?
private: Accessible only within the same class.
protected: Accessible within the same class and derived classes.
4. What is an interface?

An interface defines a contract that implementing classes must follow.

5. What is an abstract class?

An abstract class cannot be instantiated directly and may contain abstract methods that subclasses must implement.
