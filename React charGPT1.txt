Module 1: JWT Authentication
What is JWT?

JWT (JSON Web Token) is a secure token used to authenticate users.

Instead of storing the username and password on every request, the server generates a token after a successful login. The client sends this token with future requests.

React Login Example
import axios from "axios";

const login = async () => {

    const response = await axios.post(
        "http://localhost:8080/auth/login",
        {
            username: "admin",
            password: "admin123"
        }
    );

    localStorage.setItem("token", response.data.token);

};
Sending JWT Token
const token = localStorage.getItem("token");

axios.get(
    "http://localhost:8080/employees",
    {
        headers: {
            Authorization: `Bearer ${token}`
        }
    }
);
Logout
localStorage.removeItem("token");

Step 3: Create Employee Service

EmployeeService.js

import axios from "axios";

const BASE_URL = "http://localhost:8080/employees";

export const getEmployees = () => axios.get(BASE_URL);

export const getEmployeeById = (id) =>
    axios.get(`${BASE_URL}/${id}`);

export const saveEmployee = (employee) =>
    axios.post(BASE_URL, employee);

export const updateEmployee = (id, employee) =>
    axios.put(`${BASE_URL}/${id}`, employee);

export const deleteEmployee = (id) =>
    axios.delete(`${BASE_URL}/${id}`);
