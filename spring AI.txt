What is Artificial Intelligence?
Artificial Intelligence (AI) is the capability of a computer system to perform tasks that normally require human intelligence.

Examples include:

Understanding language

Recognizing images

Making decisions

Solving problems

Writing code

Answering questions

Translating languages

Machine Learning is a branch of AI where computers learn from data instead of relying only on manually written rules.

Generative AI creates new content instead of only analyzing existing data.

What is a Large Language Model (LLM)?
A Large Language Model (LLM) is an AI model trained on massive amounts of text to understand and generate human-like language.

It predicts the next most likely token (word or word fragment) in a sequence.

Examples:

OpenAI GPT

Google Gemini

Anthropic Claude

Meta Llama

Mistral

Common AI Terminology
Prompt
The instruction or question given to the AI.

Example:

Explain Java Streams.
Token
A token is a unit of text processed by the model. It may be a whole word, part of a word, punctuation, or symbols.

Example:

"Spring Boot is awesome"
can be split into multiple tokens depending on the tokenizer.

Context Window
The amount of text the model can consider at one time while generating a response.

A larger context window allows the model to remember more of the conversation or document.

Temperature
Controls the randomness of AI responses.

Temperature	Behavior
0.0	Very deterministic
0.3	Focused and factual
0.7	Balanced
1.0	More creative
Hallucination
When an AI confidently generates information that is incorrect or unsupported.

Example:

AI:
Java was invented in 1982.
This is incorrect—Java was first released in 1995.

Embedding
An embedding converts text into numerical vectors that capture meaning, enabling semantic search and similarity comparisons.

Example:

Java Programming
↓

[0.24, 0.18, 0.91, ...]

Module 2: Introduction to Spring AI
What is Spring AI?
Spring AI is an open-source framework from the Spring ecosystem that simplifies integrating Large Language Models (LLMs) into Java and Spring Boot applications.

It provides a consistent programming model so developers can switch between AI providers with minimal code changes.

Definition
Spring AI brings AI capabilities into Spring Boot applications using familiar Spring concepts such as dependency injection, auto-configuration, and starter dependencies.

Why Spring AI?
Before Spring AI, developers had to:

Learn each AI provider's SDK.

Handle HTTP requests manually.

Parse JSON responses.

Manage authentication separately.

Write different code for different AI providers.

Spring AI abstracts the provider-specific details, allowing you to focus on application logic.

Benefits of Spring AI
Easy integration with Spring Boot.

Provider-independent programming model.

Auto-configuration.

Dependency Injection support.

Chat support.

Embeddings support.

Image generation support.

Audio model support.

Vector database integration.

Retrieval-Augmented Generation (RAG) support.

Tool/Function calling support.

Step 3: Chat Service
package com.example.service;

import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;

@Service
public class ChatService {

    private final ChatClient chatClient;

    public ChatService(ChatClient.Builder builder) {
        this.chatClient = builder.build();
    }

    public String askAI(String question) {

        return chatClient
                .prompt(question)
                .call()
                .content();
    }
}
Understanding the Code
Constructor Injection
public ChatService(ChatClient.Builder builder)
Spring injects a ChatClient.Builder.

Build ChatClient
this.chatClient = builder.build();
Creates the ChatClient instance.

Send Prompt
chatClient.prompt(question)
Sends the user's question to the model.

Call AI
.call()
Invokes the configured AI provider.

Extract Response
.content()
Returns only the generated text.

What is Prompt Engineering?
Prompt Engineering is the process of designing clear and effective instructions that guide an AI model to produce the desired output.

Think of a prompt as giving requirements to a software developer:

Vague requirements → Vague results.

Clear requirements → Better results.

What is RAG?
Retrieval-Augmented Generation (RAG) is an AI technique that combines:

Large Language Models (LLMs)

Vector Databases

Semantic Search

Instead of relying only on the model's training data, RAG retrieves relevant information from your own documents and provides it to the LLM before generating an answer.
