 What is AWS?

AWS (Amazon Web Services) is a cloud computing platform that provides services such as compute, storage, databases, networking, security, monitoring, messaging, and serverless computing on a pay-as-you-go model.

Examples:

Compute       → EC2
Storage       → S3
Database      → RDS
Networking    → VPC
Security      → IAM
Serverless    → Lambda
Monitoring    → CloudWatch

2. What is Cloud Computing?

Cloud computing is the delivery of computing resources such as servers, storage, databases, networking, and software over the internet instead of maintaining physical infrastructure ourselves.


3. What are the major cloud service models?

Model	Meaning	Example

IaaS	Infrastructure as a Service	EC2
PaaS	Platform as a Service	Elastic Beanstalk
SaaS	Software as a Service	Web-based applications


For example:

IaaS → You manage the OS and application
PaaS → AWS manages much of the infrastructure
SaaS → You mainly use the application

4. What is an AWS Region?

A Region is a geographic area where AWS has infrastructure.

Mumbai
Hyderabad
Singapore
Frankfurt
Virginia

Applications can be deployed in a region based on factors such as latency, compliance, and availability requirements.

5. What is an Availability Zone?

An Availability Zone (AZ) is an isolated infrastructure location within an AWS Region.
A region typically contains multiple AZs.
AWS Region
│
├── AZ-1
├── AZ-2
└── AZ-3

Using multiple AZs helps improve application availability.

6. What is IAM?

IAM stands for Identity and Access Management. It controls authentication and authorization for AWS resources.
Authentication → Who are you?
Authorization  → What can you access?

7. What is an IAM User?

An IAM User represents an identity that can authenticate to AWS and receive permissions.
For example:
Developer
Tester
Administrator

8. What is an IAM Group?

An IAM Group is a collection of IAM users.
Example:
Developers Group
│
├── User1
├── User2
└── User3

Permissions can be assigned to the group rather than individually to every user.

9. What is an IAM Policy?

An IAM policy is a JSON document that defines permissions.
Example:
{
  "Effect": "Allow",
  "Action": "s3:GetObject",
  "Resource": "*"
}

It defines:
Effect
Action
Resource

10. What is an IAM Role?

An IAM Role is an identity with permissions that can be assumed by AWS services, applications, or users.

A very common example:

EC2
 ↓
IAM Role
 ↓
S3 Permission
 ↓
S3

This allows an application running on EC2 to access S3 without storing AWS access keys in the application.

11. IAM User vs IAM Role?

IAM User			IAM Role
==============================================================
Represents a specific identity	Represents assumable permissions
Often used for human identities	Commonly used by AWS services/applications
Can have long-term credentials	Provides temporary credentials when assumed
Example: developer	Example: EC2 → S3


12. What is the Principle of Least Privilege?

Give a user, application, or service only the permissions required to perform its task.
For example, if an application only needs to upload files:
Allow:
s3:PutObject

instead of:
Allow:
s3:*


13. What is EC2?

EC2 stands for Elastic Compute Cloud. It provides virtual servers in AWS.
You can use EC2 to run:
Java
Spring Boot
Node.js
Python
Docker
Web servers

14. What is an AMI?

AMI stands for Amazon Machine Image.
It is a template used to launch an EC2 instance.

Examples:
Ubuntu
Amazon Linux
Windows Server

15. What is an EC2 Instance Type?

An instance type defines the compute characteristics of an EC2 instance, such as:
CPU
Memory
Network performance
Storage characteristics

The appropriate instance type depends on workload requirements.

16. What is a Key Pair?

A key pair is used to securely authenticate to an EC2 instance.
It consists of:
Public Key
Private Key

For Linux EC2, the private key is commonly used for SSH.

Example:
ssh -i "my-key.pem" ubuntu@<PUBLIC-IP>

The private key should be protected and never shared.

17. What is a Security Group?

A Security Group is a virtual firewall associated with resources such as EC2 instances.
For example:
Inbound
22    → SSH
80    → HTTP
443   → HTTPS
8080  → Spring Boot

Security Groups are stateful.

18. What is the difference between Security Group and NACL?

Security Group					NACL
================================================================
Works at instance/resource level	Works at subnet level
Stateful				Stateless
Supports allow rules			Supports allow and deny rules
Commonly used for instance traffic control	Additional subnet-level network control


19. What is EBS?

EBS stands for Elastic Block Store.
It provides block-level storage for EC2.
Think:
EC2
 |
 └── EBS
      └── Disk

It can be used for operating-system and application data.

20. What happens when an EC2 instance is stopped?


The instance is stopped and can generally be started again later while retaining its EBS-backed storage.
However, AWS charges can still apply to resources such as EBS storage and certain public IPv4 configurations, so stopping an instance does not necessarily make the overall resource cost zero.

21. What is the difference between Stop and Terminate?

Stop
Running → Stopped

The instance can generally be started again.

Terminate
Running → Terminated

The instance is permanently removed.


22. What is Amazon S3?

S3 stands for Simple Storage Service. It is an object storage service used to store files and other objects.
Examples:
PDF
Images
Videos
Backups
Logs
Documents
Static website assets

23. What is an S3 Bucket?

A bucket is a container for S3 objects.

Example:
company-documents
│
├── employees/
├── invoices/
└── reports/

24. What is an S3 Object?

An object is the actual data stored in S3 along with associated metadata.
Example:
resume.pdf
profile.jpg
invoice.pdf

25. What is an S3 Key?

The key is the unique name of an object within a bucket.
Example:
employees/101/resume.pdf

The complete string is the object's key.

26. Is S3 a file system?

No. S3 is fundamentally an object storage service, not a traditional file system.
The / characters in keys provide a folder-like organizational structure.

27. What is S3 Versioning?

Versioning allows S3 to retain multiple versions of an object.
resume.pdf
   │
   ├── Version 1
   ├── Version 2
   └── Version 3

It helps protect against accidental overwrites and deletions.

28. What is an S3 Lifecycle Rule?

A lifecycle rule automatically transitions or deletes objects according to defined conditions.

For example:
Day 0
 ↓
S3 Standard

Day 30
 ↓
Infrequent Access

Day 90
 ↓
Archive

This can help manage storage costs and retention.

29. What is a Presigned URL?

A presigned URL is a temporary URL that provides authorized access to an S3 object.

Example:
User
 ↓
Spring Boot
 ↓
Generate Presigned URL
 ↓
S3
 ↓
Temporary Download

It allows a private object to be accessed without making the entire bucket public.

30. How would you upload a file from Spring Boot to S3?

React
  ↓
MultipartFile
  ↓
Spring Boot REST API
  ↓
AWS SDK
  ↓
S3 PutObject
  ↓
S3 Bucket

In Java, the AWS SDK for Java 2.x provides S3Client for S3 operations.

Example:
PutObjectRequest request =
    PutObjectRequest.builder()
        .bucket(bucketName)
        .key(key)
        .contentType(file.getContentType())
        .build();

s3Client.putObject(
    request,
    RequestBody.fromInputStream(
        file.getInputStream(),
        file.getSize()
    )
);


31. What is VPC?

VPC stands for Virtual Private Cloud.
It provides an isolated virtual network in AWS where you can launch resources such as EC2 instances.
Basic architecture:
VPC
│
├── Public Subnet
│     └── EC2
│
└── Private Subnet
      └── RDS

32. What is a Subnet?

A subnet is a range of IP addresses within a VPC.
For example:
VPC
10.0.0.0/16
│
├── Public Subnet
│   10.0.1.0/24
│
└── Private Subnet
    10.0.2.0/24

33. What is an Internet Gateway?

An Internet Gateway provides a path between a VPC and the internet for resources whose subnet routing and security configuration allow internet access.
Typical architecture:
Internet
   |
Internet Gateway
   |
Route Table
   |
Public Subnet
   |
EC2

34. What is a NAT Gateway?

A NAT Gateway allows resources in a private subnet to initiate outbound connections to the internet without allowing unsolicited inbound internet connections directly to those resources.

Example:
Private EC2
    |
    ↓
NAT Gateway
    |
    ↓
Internet

35. Public Subnet vs Private Subnet?

Public subnet:
A subnet is considered public when its route table has a route to an Internet Gateway and resources have the necessary addressing and security configuration.

Private subnet:
A subnet without a direct route to an Internet Gateway.

Typical architecture:

Internet
   |
Load Balancer
   |
Public Subnet
   |
Private Subnet
   |
RDS


36. What is Amazon RDS?

RDS stands for Relational Database Service. It is a managed service for relational databases.


MySQL

Oracle
SQL Server
Aurora

37. RDS vs Database on EC2?

With a database installed on EC2, you are responsible for much more of the operating system and database administration.
With RDS, AWS manages many infrastructure-level tasks such as:
Provisioning
Backups
Patching
Monitoring
Certain high-availability capabilities

depending on configuration.

39. What is Auto Scaling?


Auto Scaling automatically adjusts the number of EC2 instances based on configured policies and conditions.

For example:

Normal traffic
     ↓
2 EC2 instances

High traffic
     ↓
4 EC2 instances

When demand decreases, instances can be reduced according to the configured policy.

40. What is CloudWatch?

Amazon CloudWatch is used for monitoring AWS resources and applications.
It can monitor things such as:
CPU utilization
Memory/application metrics
Network activity
Logs
Alarms

For example:

      ↓

      ↓
Notification / Automation


41. What is AWS Lambda?

AWS Lambda is a serverless compute service that runs code in response to events without requiring you to manage servers directly.

Example:

S3 File Upload
      ↓
Lambda
      ↓
Process Image

42. EC2 vs Lambda?

Long-running applications possible	Event/function-oriented execution
More infrastructure control	Less infrastructure management
Pay based on configured resources/time	Pay based on execution/resource usage

46. How would you secure an S3 file?

I would normally:
- Keep the bucket private.
- Use IAM permissions with least privilege.
- Avoid unnecessary public access.
- Use encryption.
- Use presigned URLs when temporary direct access is required.
- Enable versioning where appropriate.
- Apply lifecycle policies where appropriate.
