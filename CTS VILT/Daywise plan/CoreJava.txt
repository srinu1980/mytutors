Scanner Class
=================
	This class is used to take input values through keyboard.

This class is derived from "util" package.


Whenever use this class, first we need to import this package.
To  import this package like

	import java.util.Scanner;



Syntax for Scanner Class
=======================

	Scanner objectName =new Scanner(System.in);

Important methods are :
========================

	objectName.nextInt()
		nextDouble()
		nextLong()
		next()
	


Operators
=============
	An operator is a symbol, which is used to perform any operations between operands.

These operators are :

1. Arithmatic operators
	+	-	 *  	/  	%

2. Relational operators
	>  <   ==   !=     >=    <=

3. Logical operators

	&&	And
	||	OR
	!	Not
4. Assignment operator

	=

	This operator is used to assign right value or expression to left-side variable.

Ex:
	a=10;
	res=a+b;

6. Ternary operator

	(condition) ? true-statements : false-statements

7. Unary operators

	++   -> increment operator
	--	-> decrement operator

8. Bitwise operators

	&	|	

	>>	<<



Array
===========

	An array is a collection of similar datypes.
	All elements are stored in memory continouslly.
	Array index start with zero end with n-1.

	Arrays are 

		Single Dimentional array

		Multi dimentional array


To declare an array
=======================

syntax:
		datatype []arrayname;


ex:	int []arr;


To allocate memory 
===================

syntax:
		arrayname =new datatype[size];

ex:
		arr=new int[10];


To declare & allocate memory as
===================================

syntax:

	datatype []arrayname =new datatype[size];

ex:
	int []arr=new int[10];




To declare & allocate memory for multidimentionala array
===================================

syntax:

	datatype [][]arrayname =new datatype[rows][cols];

ex:
	int [][]arr=new int[2][3];



To initialize an array
====================

syn:
		datatype []arr={value1, value2,value3,....};
