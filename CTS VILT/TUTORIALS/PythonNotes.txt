Operators in Python
=========================

Operators are symbols that perform operations on variables and values.

1. Arithmetic Operators

Used for mathematical calculations.

a, b = 10, 3

print(a + b)  # Addition → 13
print(a - b)  # Subtraction → 7
print(a * b)  # Multiplication → 30
print(a / b)  # Division (float) → 3.333...
print(a // b) # Floor Division → 3
print(a % b)  # Modulus (remainder) → 1
print(a ** b) # Exponentiation (power) → 1000


2. Comparison (Relational) Operators

Used to compare values (returns True or False).

x, y = 5, 10

print(x == y)  # Equal → False
print(x != y)  # Not equal → True
print(x > y)   # Greater than → False
print(x < y)   # Less than → True
print(x >= 5)  # Greater or equal → True
print(y <= 10) # Less or equal → True

3. Logical Operators

Used to combine conditions.

a, b = True, False

print(a and b)  # AND → False
print(a or b)   # OR  → True
print(not a)    # NOT → False

4. Assignment Operators

Used to assign values to variables.

x = 10
x += 5   # x = x + 5 → 15
x -= 3   # x = x - 3 → 12
x *= 2   # x = x * 2 → 24
x /= 4   # x = x / 4 → 6.0
x %= 5   # x = x % 5 → 1.0
x **= 3  # x = x ** 3 → 1.0

5. Bitwise Operators

Work at the binary (bit) level.

a, b = 5, 3   # In binary: a=101, b=011

print(a & b)  # AND → 1  (001)
print(a | b)  # OR  → 7  (111)
print(a ^ b)  # XOR → 6  (110)
print(~a)     # NOT → -6 (inverts bits)


6. Membership Operators

Check if a value exists in a sequence.

fruits = ["apple", "banana"]

print("apple" in fruits)   # True
print("mango" not in fruits) # True

7. Identity Operators

Check if two objects refer to the same memory location.

x = [1, 2, 3]
y = x
z = [1, 2, 3]

print(x is y)      # True (same object)
print(x is z)      # False (different objects, same values)
print(x is not z)  # True

What is a Dictionary in Python?
==================================

A dictionary is a built-in data type in Python used to store data in key-value pairs.

It is unordered (in Python < 3.7), but from Python 3.7+ dictionaries maintain insertion order.

It is mutable, meaning you can change, add, or remove items.

Keys must be unique and immutable (like strings, numbers, tuples).

Values can be of any data type (string, int, list, dict, etc.).

 Syntax

dictionary_name = {
    "key1": "value1",
    "key2": "value2",
    "key3": "value3"
}


 Example 1: Creating and Accessing Dictionary

student = {
    "name": "Nancy",
    "age": 21,
    "course": "Computer Science",
    "skills": ["Python", "Java", "SQL"]
}

# Access values using keys
print(student["name"])   # Nancy
print(student["skills"]) # ['Python', 'Java', 'SQL']

# Using get() (safe way, avoids error if key not found)
print(student.get("age"))   # 21
print(student.get("grade")) # None (instead of error)


 Example 2: Adding, Updating, and Deleting

student["age"] = 22               # Update value
student["grade"] = "A"            # Add new key-value
del student["course"]             # Delete a key
removed = student.pop("skills")   # Remove and return value

print(student)
# {'name': 'Nancy', 'age': 22, 'grade': 'A'}

print("Removed:", removed)
# Removed: ['Python', 'Java', 'SQL']

What is a Module in Python?
============================

A module in Python is simply a file containing Python code (functions, classes, variables).

The file has a .py extension.

Modules help in code reusability, readability, and organization.

Instead of writing the same functions again, you can put them in a module and import them wherever needed.


 Types of Modules
==================

Built-in Modules – Already provided by Python (e.g., math, datetime, os).

User-Defined Modules – Created by programmers (your own .py file).

Third-Party Modules – Installed using pip (e.g., numpy, pandas).


 How to Create a User-Defined Module
=========================================


Create a .py file with functions, variables, or classes.

Import it into another Python program.

Use its functions/variables.



Simple User-Defined Module
===============================

Step 1 – Create a module file (mymath.py)

# mymath.py (User Defined Module)

def add(a, b):
    return a + b

def subtract(a, b):
    return a - b

def multiply(a, b):
    return a * b

def divide(a, b):
    if b != 0:
        return a / b
    else:
        return "Division by zero not allowed"




Step 2 – Use it in another program (main.py)
# main.py

import mymath  # Import user-defined module

print("Addition:", mymath.add(10, 5))
print("Subtraction:", mymath.subtract(10, 5))
print("Multiplication:", mymath.multiply(10, 5))
print("Division:", mymath.divide(10, 5))




 Example 2: Real-Time Example – Employee Salary Module
=========================================================

Step 1 – Create module (salary.py)

# salary.py

def calculate_bonus(salary, performance):
    if performance == "A":
        return salary * 0.20
    elif performance == "B":
        return salary * 0.10
    else:
        return salary * 0.05

def calculate_total_salary(salary, performance):
    bonus = calculate_bonus(salary, performance)
    return salary + bonus

Step 2 – Use it in another program (company.py)
# company.py

import salary

basic_salary = 50000
performance = "A"

bonus = salary.calculate_bonus(basic_salary, performance)
total = salary.calculate_total_salary(basic_salary, performance)

print(f"Employee Bonus: {bonus}")
print(f"Total Salary: {total}")


 Output:
==============

Employee Bonus: 10000.0
Total Salary: 60000.0

 File Handling
===================

File handling in Python allows us to create, read, write, and delete files on the system.

It provides built-in functions to interact with files easily.


 Opening a File
====================

We use the open() function.

file = open("example.txt", "mode")


Modes:

	"r" → Read (default) – file must exist.

	"w" → Write – creates new file or overwrites existing.

	"a" → Append – adds data at the end of file.

	"x" → Create – creates new file, error if file exists.

	"b" → Binary mode (e.g., images).

	"t" → Text mode (default).


 Example:



f = open("myfile.txt", "r")   # open file for reading
print(f.read())
f.close()


Reading from a File
======================

f = open("myfile.txt", "r")

print(f.read())         # Read entire file
print(f.read(10))       # Read first 10 characters
print(f.readline())     # Read one line
print(f.readlines())    # Read all lines into a list

f.close()


 Writing to a File
=====================

f = open("myfile.txt", "w")
f.write("Hello, Python!\n")
f.write("This is file handling example.")
f.close()


 Note: "w" will overwrite the file. Use "a" to append.


f = open("myfile.txt", "a")

f.write("\nNew line added.")

f.close()


 Using with 
==================

When we use with, the file is automatically closed.

with open("myfile.txt", "r") as f:
    content = f.read()
    print(content)




 Iterating Over a File
==========================
with open("myfile.txt", "r") as f:
    for line in f:
        print(line.strip())


File Handling with Binary Files
================================

Ex: Copy an image file


with open("image.jpg", "rb") as f1:
    data = f1.read()

with open("copy.jpg", "wb") as f2:
    f2.write(data)



 Deleting a File
=================

We use the os module.

import os

# remove file
os.remove("myfile.txt")

# check if file exists before deleting
if os.path.exists("myfile.txt"):
    os.remove("myfile.txt")
else:
    print("File not found")
















OOPs in Python

OOP (Object-Oriented Programming) is a way of structuring programs around objects (real-world entities) and classes (blueprints).


1. Class and Object

Class → A blueprint/template for creating objects.

Object → An instance of a class.

class Person:
    def __init__(self, name, age):   # Constructor
        self.name = name
        self.age = age

    def greet(self):   # Method
        print(f"Hello, my name is {self.name} and I am {self.age} years old.")


# Creating objects
p1 = Person("Rahul", 25)

2. Pillars of OOPs in Python

1) Encapsulation

Wrapping variables & methods inside a class.

Use public, protected, private attributes.

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance   # private attribute

    def deposit(self, amount):
        self.__balance += amount

    def get_balance(self):
        return self.__balance

acc = BankAccount(1000)
acc.deposit(500)
print(acc.get_balance())   # 1500



2) Inheritance

Allows one class to inherit properties & methods from another.

class Animal:
    def speak(self):
        print("I am an animal")

class Dog(Animal):   # Dog inherits from Animal
    def speak(self):
        print("Woof! Woof!")

d = Dog()
d.speak()   # Woof! Woof!


 Types of inheritance:

Single

Multiple

Multilevel

Hierarchical



3) Polymorphism

One interface, many implementations.

Achieved by method overriding / overloading-like behavior.

class Bird:
    def fly(self):
        print("Some birds can fly")

class Sparrow(Bird):
    def fly(self):
        print("Sparrow can fly high")

class Penguin(Bird):
    def fly(self):
        print("Penguins cannot fly")

for b in (Sparrow(), Penguin()):
    b.fly()

In Python, we usually prefer @property because it makes code cleaner and looks like normal attribute access (without explicitly calling get_...() and set_...() methods).

Employ class using @property:
==============================

class Employ:
    def __init__(self, emp_id, name, salary):
        self._emp_id = emp_id
        self._name = name
        self._salary = salary

    # emp_id property (read-only)
    @property
    def emp_id(self):
        return self._emp_id

    # name property (getter + setter)
    @property
    def name(self):
        return self._name

    @name.setter
    def name(self, value):
        self._name = value

    # salary property (getter + setter with validation)
    @property
    def salary(self):
        return self._salary

    @salary.setter
    def salary(self, value):
        if value > 0:
            self._salary = value
        else:
            print("Salary must be positive!")


# Create object
emp1 = Employ(101, "Srinivas", 50000)

# Access attributes like normal variables

print("Employee ID:", emp1.emp_id)     # read-only
print("Employee Name:", emp1.name)
print("Employee Salary:", emp1.salary)

# Update attributes (uses setter behind the scenes)
emp1.name = "Rao"
emp1.salary = 60000

print("\nAfter update:")
print("Employee ID:", emp1.emp_id)
print("Employee Name:", emp1.name)
print("Employee Salary:", emp1.salary)
