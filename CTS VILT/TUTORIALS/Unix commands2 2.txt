
File Manipulation Unix Command
=========================




cp

Copies files or directories.
cp file1.txt file2.txt

mv
Moves files or directories.

mv file1.txt Documents

rm
Remove files or directories.

rm old_file.txt

chmod
Changes the permissions of a file or directory.

chmod 644 file.txt

chown
Changes the owner and group of a file or directory.

chown user:group file.txt

cat	Concatenates files and displays their contents.	

cat file1.txt file2.txt

head	Displays the first few lines of a file.	
head file.txt

tail	Displays the last few lines of a file.	
tail file.txt

more	Displays the contents of a file page by page.	

more file.txt

less	Displays the contents of a file with advanced navigation features.	
less file.txt

diff	Compares files line by line.	
diff file1.txt file2.txt






1. File Management Commands

Command	Description	Example

ls	List files	ls -l
touch	Create an empty file	touch file.txt
cat	View file content	cat file.txt
cp	Copy files	cp file.txt backup.txt
mv	Move or rename file	mv file.txt newfile.txt
rm	Delete file	rm file.txt
file	Show file type	file file.txt

pwd	Show current directory	pwd
ls	List directory contents	ls -la /etc


 3. File Permissions / Access Modes

Command	Description	Example

chmod	Change file permissions	chmod 755 file.sh
chown	Change file owner	chown user1 file.txt
chgrp	Change group ownership	chgrp dev file.txt
umask	Default permission mask	umask 022

🔸 Permission Codes:

r = read, w = write, x = execute

Numeric: 7 = rwx, 6 = rw-, 5 = r-x, 4 = r--
