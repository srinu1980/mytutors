15. What are the key features of Unix?

--Multi-user system
--Multitasking capabilities
--Portability
--Hierarchical file system
--Shell for command-line interaction


16. What is the Unix file system structure?

A hierarchical structure starting with the root directory /. Key directories:

/bin: Binary executables
/etc: Configuration files
/home: User directories
/tmp: Temporary files
/var: Variable data like logs



17. What are the different types of files in Unix?

Regular files (-)
Directory files (d)
Symbolic links (l)
Device files (b, c for block and character devices)
Pipes and sockets (p, s)
