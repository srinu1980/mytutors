Factorial of a Number (Recursive Function)


factorial() {
    if [ $1 -le 1 ]; then
        echo 1
    else
        local prev=$(factorial $(( $1 - 1 )))
        echo $(( $1 * prev ))

    fi
}

result=$(factorial 5)
echo "Factorial is: $result"

awk command
=====================
awk is a scripting language, and it is helpful when working in the command line. It's also a widely used command for text processing.


Awk is mostly used for pattern scanning and processing. It searches one or more files to see if they contain lines that matches with the specified patterns and then perform the associated actions. 

Awk is abbreviated from the names of the developers - Aho, Weinberger, and Kernighan. 


Its simplest form, the awk command is followed by a set of single quotation marks and a set of curly braces, with the name of the file you want to search through mentioned last.

Syntax:

awk options 'selection _criteria {action }' input-file > output-file


Option		Description
=================================================
-F	Sets a custom field separator

-f	Reads awk program from a file

'{}'	Encloses action to take on match


WHAT CAN WE DO WITH AWK? 
========================

1. AWK Operations: 

a Scans a file line by line 
b Splits each input line into fields 
c Compares input line/fields to pattern 
d Performs actions on matched lines 

2. Useful For: 

a Transform data files 
b Produce formatted reports 

3. Programming Constructs: 

a Format output lines 
b Arithmetic and string operations 
c Conditionals and loops

grep command in Unix/Linux
==============================

Grep is a useful command to search for matching patterns in a file. 
grep is short for "global regular expression print".

If you are a system admin who needs to scrape through log files or a developer trying to find certain occurrences in the code file, then grep is a powerful command to use.


Syntax of the grep Command


grep [OPTION] PATTERNS [FILE]


the following options that can be used with grep:
-----------------------------------
-i, --ignore-case: Ignores case distinctions in patterns and input data.

-v, --invert-match: Selects the non-matching lines of the provided input 	pattern.

-n, --line-number: Prefix each line of the matching output with the line 	number in the input file.

-w: Find the exact matching word from the input file or string.

-c: Count the number of occurrences of the provided pattern.

sed 's/old_word/new_word/g' filename


The substitute flag /g global replacement specifies the sed command to replace all the occurrences of the string in the line.

sed 's/unix/linux/g' file.txt

Handling Errors with Exit Codes
---------------------------------
In Bash scripting, commands and scripts can indicate success or failure by returning an exit code. 

An exit code of 0 typically signifies success, while any non-zero exit code indicates an error.



Checking Exit Codes
-----------------------
After executing a command, you can access its exit code using the special variable $?

ls /path/to/nonexistent/directory

exit_code=$?

if [ $exit_code -ne 0 ]; then
    echo "An error occurred."
fi




Exit Codes in Functions
---------------------------

When writing functions, you can also use the return statement to specify an exit code. 

check_file_exists()
 {
    if [ -e "$1" ]; then          #It returns True if any type of file exists.
        return 0  # Success
    
   else
   
     return 1  # Error

    fi
}




check_file_exists "filename.txt"

exit_code=$?

if [ $exit_code -ne 0 ]; then
    echo "The file does not exist."
fi



the check_file_exists function checks if a file exists. 
It returns 0 if the file exists (success) and 1 if the file does not exist (error). 

We capture the exit code using $? and display an error message if needed.




Debugging Techniques
==========================

Debugging is an essential skill in scripting. 
It helps identify and resolve issues in your code. 
Bash provides several techniques to aid in debugging:


Printing Debug Information
==============================
Adding print statements to your script can help you understand the flow of execution and the values of variables at specific points.

Enabling Debug Mode
--------------------
Bash offers a debug mode (-x) that prints each command and its arguments as they are executed. 

You can enable it by adding set -x at the beginning of your script or by running your script with the -x option.



The debug mode provides detailed information about the execution flow, making it easier to identify errors or unexpected behaviors.


set -x  print the statement after interpreting meta characters and variables

set -v  print the statement before interpreting meta characters and variables
