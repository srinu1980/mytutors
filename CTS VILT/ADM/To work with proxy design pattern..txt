To work with proxy design pattern.

Concept Explanation:

The Proxy design pattern provides a surrogate or placeholder for another object to control access to it. This pattern is useful when you want to add an extra layer of control over access to an object. The proxy helps in implementing access control, logging, monitoring, lazy initialization, and remote object representation. It typically handles additional functionality such as resource management, access restrictions, and performance optimizations. It is also known as the Surrogate Pattern.

Concept Implementation:

In this program, the Proxy design pattern is implemented to control access to the locker system. The ILockerAccess interface defines the method getLockerAccess for accessing the locker. The LockerService class implements this interface, providing the actual implementation of locker access. The ProxyService class also implements the ILockerAccess interface, acting as a proxy to the LockerService. It checks the authentication of the customer by iterating through the list obtained from the AuthenticationRepo and invokes the getLockerAccess method of LockerService only if the customer is authenticated. Otherwise, it returns "Unauthorized". This ensures controlled access to the locker system based on authentication status.

Scenario:

Software for Locker system is created which returns the name of the customer who can access the locker. Only selected members are allowed to access the locker. If a customer tries to access the locker and if he is an authenticated customer, the locker system should return the message <<name>> allowed to access the locker.

This method creates few customer's and returns a list of customers who are the authenticated customers who can access the locker.

ILockerAccess interface is created with the  below method
String getLockerAccess(String lockerId,String name)

LockerService class should implement ILockerAccess

Override the getLockerAccess.

This method should return the string which should be <<name>> allowed to access the locker.

ProxyService class should implement ILockerAccess

Override the getLockerAccess as below,

Create an object for AuthenticationRepo
Iterate the list from AuthenticationRepo and check if the name and locker id match with the passed name and locker id, if it matches invoke the getLockerAccess method of LockerService else return "Unauthorized"

LockerSystem/src/ProxyService.java
     import java.util.List;
     
     public class ProxyService implements ILockerAccess {
     
     	//Fill the code
     	@Override
     	public String getLockerAccess(String name, String lockerId) 
     	{	
     		
    		AuthenticationRepo ar = new AuthenticationRepo();
    		
    		List<Customer> cList = ar.getLockerCredentials();
    		
    		LockerService lockerObj = new LockerService();
    		String msg = null;
    		for(Customer c : cList)
    		{
    			if (c.getCustomerName().equals(name) && c.getLockerId().equals(lockerId))
    			{
    				msg = lockerObj.getLockerAccess(name, lockerId);
    				break;
    			}
    			else
    				msg = "Unauthorized";
    		}
    		return msg;
    	}
    
    }
