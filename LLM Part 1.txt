Topic 6: Top-p Sampling
Instead of looking at every possible next token, the model considers the smallest set of likely tokens whose combined probability reaches p.

Example

Predicted probabilities:

Java      50%
Python    20%
C#        10%
Go         8%
Rust       7%
Others     5%
If

Top-p = 0.70
The model keeps

Java
Python
because 50% + 20% = 70%.

Lower top-p = more focused responses.

Higher top-p = more diverse responses.

Temperature vs Top-p
Temperature	Top-p
Changes randomness	Limits candidate token pool
Controls creativity	Controls diversity
High = Creative	High = More choices
Low = Predictable	Low = Focused
In practice, many applications adjust either temperature or top-p, rather than aggressively tuning both at once.

What is Prompt Engineering?
Definition
Prompt Engineering is the process of designing effective prompts that guide an LLM to generate accurate, relevant, and useful responses.

Real-World Example
Imagine you hire a carpenter.

Poor Instruction
Build a table.
The carpenter has many unanswered questions.

What size?

What material?

Dining table?

Office table?

The result may not match your expectations.

Better Instruction
Build a wooden office table.

Dimensions:
120 cm × 60 cm

Color:
Dark Brown

Need one drawer.

Budget:
₹8,000
Now the carpenter understands exactly what you want.

LLMs work the same way.

Definition
You ask the model to perform a task without providing any examples.

The model relies on its general training.

Example

Output

శుభోదయం
Another Example

Prompt

The model already knows Java Collections and provides an explanation.

Real-World Example
Teacher asks:

No sample answer is given.

Student answers based on knowledge.

Advantages
Simple

Fast

Good for common tasks

Limitations
May not match your desired format or style.

Pattern 3: Chain-of-Thought Prompting
Definition
Encourages the model to reason through a problem step by step before producing the final answer.

Note: For end-user applications, it's often better to ask for a concise explanation or step-by-step solution rather than explicitly requesting the model's internal reasoning. Many reasoning-capable models perform internal reasoning automatically.

Example
Prompt

A shop sells one pen for ₹20.

Rahul buys 4 pens.

How much does he pay?

Show the calculation.
Output

Price of one pen = ₹20

Number of pens = 4

Total = 20 × 4

Answer = ₹80
Real-World Example
School Mathematics

Teacher says:

Show every calculation.
Instead of only writing

₹80
Benefits
Better accuracy

Useful for math

Useful for coding

Useful for logical reasoning

Topic 6: Top-p Sampling
Instead of looking at every possible next token, the model considers the smallest set of likely tokens whose combined probability reaches p.

Example

Predicted probabilities:

Java      50%
Python    20%
C#        10%
Go         8%
Rust       7%
Others     5%
If

Top-p = 0.70
The model keeps

Java
Python
because 50% + 20% = 70%.

Lower top-p = more focused responses.

Higher top-p = more diverse responses.

Temperature vs Top-p
Temperature	Top-p
Changes randomness	Limits candidate token pool
Controls creativity	Controls diversity
High = Creative	High = More choices
Low = Predictable	Low = Focused
In practice, many applications adjust either temperature or top-p, rather than aggressively tuning both at once.

Self-Attention
The model decides which earlier words are most relevant when predicting the next token.

Words become vectors.

Why Structured Output?
Suppose a user asks:

Book a flight from Chennai to Hyderabad tomorrow.

This is not enough.

Your application needs structured data like:

  "date": "Tomorrow"
}
Now the backend can call a flight booking API.

What is Prompt Engineering?
Definition
Prompt Engineering is the process of designing effective prompts that guide an LLM to generate accurate, relevant, and useful responses.

Real-World Example
Imagine you hire a carpenter.

Poor Instruction
Build a table.
The carpenter has many unanswered questions.

Office table?

Better Instruction
Build a wooden office table.

Dimensions:
120 cm × 60 cm

Color:
Dark Brown

Need one drawer.

Budget:
₹8,000
Now the carpenter understands exactly what you want.

LLMs work the same way.

Pattern 3: Chain-of-Thought Prompting
Definition
Encourages the model to reason through a problem step by step before producing the final answer.

Note: For end-user applications, it's often better to ask for a concise explanation or step-by-step solution rather than explicitly requesting the model's internal reasoning. Many reasoning-capable models perform internal reasoning automatically.

Price of one pen = ₹20

Number of pens = 4

Total = 20 × 4

Answer = ₹80

What is Conversation Memory?
Definition
Conversation Memory is the mechanism that allows an AI application to remember previous interactions and use them in future responses within the same conversation.

Without memory:

User:
My name is Rahul.

Assistant:
Nice to meet you.

----------------------------

User:
What's my name?

Assistant:
I don't know.
With memory:

User:
My name is Rahul.

Assistant:
Nice to meet you Rahul.

----------------------------

User:
What's my name?

Assistant:
Your name is Rahul.

Best Practices
Conversation Memory
Keep only useful history.

Avoid sending unnecessary messages.

Monitor token usage.

Summary Memory
Summarize periodically.

Preserve important facts.

Keep summaries concise.

Context Window Management
Remove obsolete messages.

Use sliding windows for recent context.

Store long-term information externally (database or vector store).

Persistent Memory
Save conversations after each interaction.

Reload history when the session starts.

Separate session-specific memory from long-term user preferences.

Modern LangChain Note
While ConversationBufferMemory and ConversationSummaryMemory are valuable learning concepts and frequently appear in interviews, newer LangChain applications increasingly use LangGraph or custom state management to handle conversation state, persistence, branching workflows, and long-running agent interactions. Learning these memory classes first provides a solid foundation before moving to more advanced stateful AI architectures.
