JavaScript Basics — Step-by-Step
1. What is JavaScript?
JavaScript (JS) is a programming language mainly used to make web pages interactive and dynamic.

Think of a web application as:

HTML       → Structure
CSS        → Presentation / Styling
JavaScript → Behavior / Logic
For example:

<button onclick="sayHello()">Click Me</button>

<script>
    function sayHello() {
        alert("Hello Srinivasa Rao!");
    }
</script>
When the user clicks the button, JavaScript executes the sayHello() function.

2. How to Run JavaScript
There are several ways.

Method 1: Inside HTML
<!DOCTYPE html>
<html>
<head>
    <title>JavaScript Demo</title>
</head>
<body>

    <h1>Hello JavaScript</h1>

    <script>
        console.log("Hello JavaScript");
    </script>

</body>
</html>
Open the HTML file in the browser.

Then:

F12 → Console
You will see:

Hello JavaScript
3. JavaScript Comments
Comments are ignored by JavaScript.

Single-line comment
// This is a comment

let age = 25;
Multi-line comment
/*
   This is
   a multi-line comment
*/

let name = "Ravi";
Comments are useful for explaining code.

4. Variables
A variable is used to store data.

JavaScript provides:

var
let
const
Modern JavaScript mainly uses:

let
const
4.1 let
Use let when the value can change.

let age = 25;

console.log(age);
Output:

25
We can change it:

let age = 25;

age = 30;

console.log(age);
Output:

30
4.2 const
Use const when the variable should not be reassigned.

const pi = 3.14;

console.log(pi);
This is not allowed:

const pi = 3.14;

pi = 4.5;
You will get an error.

Recommended practice
Value changes      → let
Value doesn't change → const
Avoid var in modern JavaScript unless you specifically need its older scoping behavior.

17. Conditional Statements
Conditional statements allow JavaScript to make decisions.

if

    console.log("Eligible to vote");
}
if...else
let age = 16;

if (age >= 18) {
    console.log("Eligible");
} else {
    console.log("Not eligible");
}
if...else if...else
let marks = 75;

if (marks >= 90) {
    console.log("A+");
} else if (marks >= 75) {
    console.log("A");
} else if (marks >= 60) {
    console.log("B");
} else {
    console.log("C");
}
18. Ternary Operator
A shorter form of if...else.

Instead of:

let age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}
You can write:

let age = 20;

let result = age >= 18 ? "Adult" : "Minor";

console.log(result);
Syntax:

condition ? valueIfTrue : valueIfFalse

   ↓

   OR

51. async / await
Modern JavaScript usually uses async/await for asynchronous code.

Instead of:

fetch(url)
    .then(response => response.json())
    .then(data => console.log(data));
You can write:

async function getEmployees() {

    const response = await fetch(
        "http://localhost:8080/api/employees"
    );

    const data = await response.json();

    console.log(data);
}
This is much easier to read.

console.log(increment());
console.log(increment());
Output:

1
2
3
The inner function remembers count.

Closures are an important JavaScript interview topic.

JavaScript DOM — Step-by-Step Explanation
1. What is DOM?
DOM = Document Object Model

When a browser loads an HTML page, it converts the HTML document into a tree of objects. JavaScript can then use these objects to read, change, add, or remove HTML elements.

For example:

<!DOCTYPE html>
<html>
<body>

    <h1 id="title">Hello</h1>
    <p>Welcome to JavaScript</p>

</body>
</html>
The browser represents it approximately like this:

Document
   │
   └── html
       ├── head
       └── body
           ├── h1
           │   └── "Hello"
           │
           └── p
               └── "Welcome to JavaScript"
JavaScript can access this tree:

const title = document.getElementById("title");

title.textContent = "Hello JavaScript";
The browser changes:

<h1 id="title">Hello</h1>
into:

<h1 id="title">Hello JavaScript</h1>
2. Why do we need DOM?
Suppose you have:

<h1>Hello</h1>
<button>Change</button>
HTML creates the page, but JavaScript can make it interactive:

User clicks button
       ↓
JavaScript event
       ↓
DOM element selected
       ↓
Element modified
       ↓
Browser updates page
For example:

<h1 id="title">Hello</h1>

<button onclick="changeText()">
    Change Text
</button>

<script>
function changeText() {
    document.getElementById("title").textContent =
        "Hello JavaScript";
}
</script>

It returns the first element that matches a CSS selector.

. → class

10. innerHTML
innerHTML gets or changes the HTML inside an element.

HTML:

<div id="box"></div>
JavaScript:

const box =
    document.getElementById("box");

box.innerHTML = "<h2>Hello</h2>";
The browser creates:

<div id="box">
    <h2>Hello</h2>
</div>
You can insert multiple elements:

box.innerHTML = `
    <h2>Employee Details</h2>
    <p>Name: Ravi</p>
    <p>Age: 30</p>
`;
textContent vs innerHTML
element.textContent = "<b>Hello</b>";
Displays:

<b>Hello</b>
But:

element.innerHTML = "<b>Hello</b>";
Displays:

Hello

because the HTML is interpreted.

For user-provided content, prefer textContent when you don't need to insert HTML, to avoid introducing HTML/script injection issues.

37. Complete DOM Example
Let's combine several concepts.

HTML
<!DOCTYPE html>
<html>

<head>
    <title>DOM Example</title>
</head>

<body>

    <h1 id="title">Employee Management</h1>

    <input
        id="employeeName"
        type="text"
        placeholder="Enter employee name">

    <button id="addButton">
        Add Employee
    </button>

    <ul id="employeeList"></ul>

    <script>

        const input =
            document.getElementById("employeeName");

        const button =
            document.getElementById("addButton");

        const list =
            document.getElementById("employeeList");


        button.addEventListener("click", function() {

            const name = input.value.trim();

            if (name === "") {
                alert("Please enter employee name");
                return;
            }

            const li =
                document.createElement("li");

            li.textContent = name;

            list.appendChild(li);

            input.value = "";

        });

    </script>

</body>
</html>
What happens?
User enters:
"Ravi"

       ↓

Clicks Add Employee

       ↓

JavaScript reads:
input.value

       ↓

createElement("li")

       ↓

li.textContent = "Ravi"

       ↓

appendChild(li)

       ↓

DOM updated

       ↓

Browser displays:

• Ravi

Don't try to memorize everything initially. For React/Angular/full-stack development, first become comfortable with these:

             DOM
              │
      ┌───────┴────────┐
      ↓                ↓
   SELECT           MODIFY
      │                │
      ├─ getElementById()
      ├─ querySelector()
      └─ querySelectorAll()
                       │
              ┌────────┼─────────┐
              ↓        ↓         ↓
        textContent  innerHTML  style
              │
              ↓
           CREATE
              │
        createElement()
              │
        appendChild()
              │
            REMOVE
              │
        remove()
              │
           EVENTS
              │
      addEventListener()
One important distinction
Since you're moving toward React, remember:

Traditional JavaScript
        ↓
JavaScript directly manipulates DOM
        ↓
document.getElementById()
querySelector()
createElement()
appendChild()
Whereas React generally works differently:

React
  ↓
State / Props
  ↓
React renders UI
  ↓
React manages DOM updates
So, learn DOM thoroughly because it teaches you how browser UI works, but when you move to React, you generally shouldn't manually manipulate the DOM for ordinary UI updates.
